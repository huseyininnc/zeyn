# Время и языки

Даты и время часто становятся источником ошибок в бизнес-приложениях: день рождения, который сдвигается на сутки, когда пользователь путешествует, смена, которая начинается на час позже после перевода часов. Zeyn даёт каждому виду значений собственный тип, так что компилятор держит их раздельно.

## Четыре типа

| Тип | Что это | Пример |
|---|---|---|
| `Date` | Календарный день без пояса | День рождения, дата счёта |
| `Time` | Время по настенным часам без пояса | Часы работы |
| `DateTime` | Точный момент, хранится в UTC | Когда была создана запись |
| `LocalDateTime` | Дата и время по настенным часам в определённом месте | Приём в 14:00 в Стамбуле |

Никогда не храните календарный день как момент. `Date` это один и тот же день в любом поясе; `DateTime` это один и тот же момент везде, который показывает разное время по настенным часам в каждом поясе.

```rust
let day = Date::new(2026, 3, 29).unwrap_or_default();
let at = Time::new(9, 30, 0).unwrap_or_default();
let slot = LocalDateTime::new(day, at);
let zone = TimeZone::named("Europe/Istanbul").unwrap_or(TimeZone::UTC);
let moment = DateTime::from_local(slot, zone)?;
let back = moment.local(zone);
```

`DateTime::from_local` возвращает ошибку для времени по настенным часам, которого в поясе не существует, например при весеннем переводе часов, вместо того чтобы гадать.

## Часы

Используйте `ctx.now()` и `ctx.today()`, а не системные часы. `ctx.today()` это сегодняшний день в поясе пользователя. Тесты фиксируют время для каждого запроса через `App::fixed_now(moment)`.

## Часовые пояса

```rust
App::new(t!("app.name"))
    .time_policy(TimePolicy::User { default: TimeZone::named("Europe/Istanbul").unwrap_or(TimeZone::UTC) })
    .time_zone_picker()
```

| Политика | Моменты показываются в |
|---|---|
| `TimePolicy::User { default }` | Поясе, о котором сообщает браузер пользователя, или `default`, пока он не сообщил |
| `TimePolicy::Organization(zone)` | Одном поясе для всех |

`.time_zone_picker()` добавляет в меню выбор пояса, чтобы пользователи могли выбрать его вручную. Прокси единого входа может также передавать пояс в заголовке (`ForwardAuth::time_zone`). Фильтры таблиц по столбцам `DateTime` читаются в поясе пользователя.

## Средства выбора

Поля даты, времени и даты со временем получают удобные для клавиатуры средства выбора (pickers). `DateOptions` ограничивает то, что можно выбрать:

```rust
Form::of(visit)
    .row(|r| r.field(Visit::day).field(Visit::arrives))
    .range(Visit::stay_from, Visit::stay_to)
    .date_options(Visit::day, DateOptions::new().no_weekends().week_numbers())
    .date_options(Visit::arrives, DateOptions::new().step_minutes(15))
```

## Выбор языка

Сервер выбирает язык по cookie `zeyn_locale`, затем по заголовку браузера `Accept-Language`, затем по языку приложения по умолчанию. `<html lang>` всегда совпадает с ним. Выбор языка в меню устанавливает cookie и подменяет страницу на месте, без перезагрузки.

## Числа, деньги и даты

Значения форматируются для языка пользователя на сервере: `1.234,56` по-турецки и `1,234.56` по-английски, даты как `29.03.2026` или `3/29/2026`, а деньги с символом валюты. Поля ввода читают те же форматы обратно.

`Money` хранит целые минимальные единицы и валюту, поэтому суммы никогда не теряют ни одной копейки:

```rust
let price = Money::tl(2_500_000);
let text = price.format("tr");
```
