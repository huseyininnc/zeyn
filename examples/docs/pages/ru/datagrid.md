# DataGrid

`DataGrid` показывает строки из действия (action), которое принимает `DataQuery` и возвращает `Page<E>`. Разбиение на страницы, сортировка, фильтры и итоги выполняются на сервере, поэтому таблица на миллион строк стоит браузеру столько же, сколько таблица на сто.

## Таблица

```rust
DataGrid::of(search_samples)
    .paging(Paging::pages(8))
    .column(Sample::code).width(110).filter()
    .column(Sample::name).flex(1).filter()
    .column(Sample::unit).width(120).filter().badge(|u| match u {
        Unit::Piece => Tone::Neutral,
        Unit::Kg => Tone::Info,
        Unit::Liter => Tone::Brand,
    })
    .column(Sample::price).width(150).avg()
    .column(Sample::stock).width(150).sum().progress(120)
    .column(Sample::active).width(100).check_icon()
    .row_style(|s| match s.stock {
        0 => Some(RowStyle::Danger),
        1..=9 => Some(RowStyle::Warning),
        _ => None,
    })
```

Сортируйте щелчком по заголовку, вводите текст в поле фильтра, перетаскивайте заголовок, чтобы переместить колонку, или её край, чтобы изменить размер. Итоги охватывают все отфильтрованные строки, а не только страницу.

## Действие

```rust
#[action(permission = "stock.product.read")]
pub async fn search_samples(q: DataQuery, store: SampleStore) -> Result<Page<Sample>> {
    Ok(q.apply(store.all()?))
}
```

`DataQuery::apply` фильтрует, сортирует, считает итоги и разбивает на страницы `Vec` в памяти, что подходит для небольших списков и тестов. Хранилище на базе базы данных читает тот же `DataQuery` (страница, сортировка, фильтры, итоги) и отвечает с помощью SQL; см. [Данные и базы данных](database.md).

## Разбиение на страницы

| Paging | Применение |
|---|---|
| `Paging::pages(n)` | Нумерованные страницы, по умолчанию 50 строк |
| `Paging::infinite(n)` | Подгружает строки при прокрутке |
| `Paging::virtual_scroll()` | Очень большие списки; на странице только видимые строки |
| `Paging::none()` | Короткие списки, умещающиеся на одной странице |

Сервер ограничивает размер страницы, что бы ни просил клиент.

## Колонки

| Вызов | Результат |
|---|---|
| `.width(px)`, `.flex(n)` | Фиксированная ширина или доля свободной ширины |
| `.filter()` | Поле фильтра, подходящее типу: текст, диапазон чисел, диапазон дат, список выбора |
| `.sum()`, `.avg()`, `.min()`, `.max()` | Итоги в нижней строке. `sum` для текстовой колонки не компилируется |
| `.badge(\|v\| tone)` | Показывает значение как метку в цвете тона на его приглушённом оттенке |
| `.status(\|v\| tone)` | Показывает значение как статус: точка в цвете тона перед обычным текстом, спокойнее бейджа |
| `.progress(max)` | Полоса от 0 до `max` |
| `.check_icon()` | Галочка для `true` |
| `.link(\|row\| effect)` | Делает ячейку ссылкой, запускающей эффект |
| `.pin_start()`, `.hidden()` | Закреплена в начале или скрыта, пока пользователь её не покажет |
| `.editable()` | Редактируется на месте, сохраняется через `.edit_with(action)` |
| `.plain()` | Целые числа без разделителей групп, для кодов и годов |
| `.wrap()` | Длинные значения переносятся на несколько строк. Без этого ячейки остаются в одну строку и заканчиваются многоточием, поэтому все строки одной высоты |

Строки высотой 40 px (32 px в компактной плотности) и разделены только линиями; `DataGrid::zebra()` затеняет каждую вторую строку для очень широких таблиц. Ссылки в ячейках выглядят как текст с начертанием 500 и подчёркиваются при наведении.

Числа и суммы выравниваются по правому краю и пишутся моноширинными цифрами. Целые числа группируются по локали пользователя (`1,234,567` по-английски, `1.234.567` по-турецки) в ячейках таблицы и в выводимых значениях, например в `DescriptionList`; идентификаторы `#[key]` никогда не группируются, а `.plain()` отключает группировку для одной колонки.

## Строки

- `.on_open(|row| effect)`: двойной щелчок или Enter на строке.
- `.row_action(label, action, |row| input)`: кнопка на каждой строке.
- `.bulk_action(label, action, M::id)`: выполняется над выбранными строками.
- `.confirm(message)` и `.tone(Tone::Danger)` сразу после `.row_action` или `.bulk_action`: спрашивает перед запуском этого действия в том же диалоге, что и `ActionButton::confirm` (фокус сначала на «Отмена»), и рисует его кнопку красной.
- `.row_menu(|row| ContextMenu)`: контекстное меню строки по правому щелчку.
- `.row_style(|row| Option<RowStyle>)`: строки danger, warning или success.
- `.add_with(create)`, `.delete_with(action, M::id)`, `.batch_edit()`: кнопка «Добавить строку»,
  кнопка и клавиша удаления и правки, сохраняемые вместе. См. [справочник DataGrid](grid.md).
- `.exportable()`: экспорт отфильтрованных строк в CSV, потоком с сервера.

## Колонки, известные во время выполнения

`DataGrid::dynamic(action)` предназначен для результатов, колонки которых приходят вместе со строками, например для предпросмотра SQL. Action возвращает `DynamicPage` с колонками (имя, подпись и `DynamicKind`, например `Integer`, `Decimal` или `Date`) и одной страницей строк в JSON:

```rust
#[action(permission = "reports.preview")]
pub async fn preview(q: DataQuery, db: Reports) -> Result<DynamicPage> {
    let span = q.span();
    db.run_preview(span.offset, span.limit).await
}

DataGrid::dynamic(preview).paging(Paging::virtual_scroll())
```

Пагинация, виртуальная прокрутка, работа с клавиатуры и форматирование чисел и дат на языке пользователя работают как в типизированном grid. Имена, подписи и ячейки экранируются, а сервер ограничивает число колонок, строк и длину текста. Grid не сортирует и не фильтрует, его строки только для чтения. Подробности в [справочнике DataGrid](grid.md).

## Поиск и группы

`.search()` ставит поле поиска над таблицей. Действие получает текст как `DataQuery::q`, который
`DataQuery::apply` сравнивает с текстовыми полями, но никогда с маскированными.
`.band(label, |b| b.column(..).column(..))` собирает столбцы под одной ячейкой заголовка. См.
[справочник DataGrid](grid.md).

## Обновление на месте

`.listens(topic)`, вызванный последним, заставляет сетку перезагружаться на месте, когда тема названа (см. [Темы](effects.md#topics)): после `ui.refresh(topic)` она перезагружает текущую страницу с сортировкой и фильтрами, а после изменения элемента фильтра с `.drives(topic)` начинает с первой страницы с новыми params экрана. Сетка перезагружается через `POST /_zeyn/grid` со всеми проверками разрешений, а param экрана, изменённый фильтром, доходит до сетки через функцию экрана, например как scope:

```rust
let mut grid = DataGrid::of(search_orders);
if let Some(region) = p.region {
    grid = grid.scope(Order::region, region);
}
grid.column(Order::number).column(Order::total).listens("orders")
```

[Справочник DataGrid](grid.md) охватывает сохранённые представления, master detail, группировку, древовидные данные, редактирование на месте, навигацию по ячейкам, копирование и вставку, виртуализацию колонок и доступность.
