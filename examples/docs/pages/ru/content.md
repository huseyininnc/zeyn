# Текст и содержимое

Страницы для чтения, такие как статьи, профили и списки, собираются из нескольких небольших компонентов. Это обычный HTML, отрисованный на сервере, без скриптов, и каждый текст берётся из файлов локализации или экранируется.

## Heading

От `Heading::h2(text)` до `Heading::h6(text)`. Заголовок экрана это единственный `h1` на странице, поэтому здесь `h1` нет: выбирайте уровень, который соответствует структуре документа, а не нужный вам размер. `.id("anchor")` позволяет ссылкам указывать на заголовок.

```rust
Heading::h2(t!("shop.new_arrivals")).id("new")
```

## Paragraph

Абзац экранированного текста. `.muted()` использует вторичный цвет текста, а `.small()` мелкий размер шрифта. Длинные слова переносятся.

```rust
Paragraph::new(t!("shop.intro"))
Paragraph::new(t!("shop.tax_note")).muted().small()
```

## MetaLine

Короткие сведения в одной строке, например дата, время чтения и категория. Разделитель (точка по центру, если `.separator("/")` не задаёт другой) скрыт от программ чтения с экрана, а пустые части пропускаются.

```rust
MetaLine::new().part(article.published.format(ctx.locale())).part(t!("blog.read_time")).part(article.category.clone())
```

## PrevNext

Ссылки на предыдущий и следующий элемент с `rel="prev"` и `rel="next"`. Они открываются без перезагрузки страницы. Слова "Previous" и "Next" берутся из текстов фреймворка; `.prev_title` и `.next_title` добавляют под ними заголовок элемента. В языках с письмом справа налево стрелки разворачиваются, а на телефонах две ссылки располагаются друг под другом.

```rust
PrevNext::new()
    .prev(article, ArticleParams { id: prev.id })
    .prev_title(prev.title.clone())
    .next(article, ArticleParams { id: next.id })
    .next_title(next.title.clone())
```

## AutoGrid

Дочерние элементы в сетке, число столбцов которой зависит от доступной ширины: столько столбцов шириной не менее `min` пикселей (240, если не задано), сколько помещается, и один столбец на телефоне. Браузер раскладывает её через `repeat(auto-fill, minmax(min(240px, 100%), 1fr))`, поэтому нет ни контрольных точек, ни скриптов. Она вмещает любые узлы: карточки, панели, таблицы. Название отличает её от `DataGrid`, который показывает строки данных.

```rust
AutoGrid::new()
    .min(220)
    .gap(4)
    .add(Card::new().title(t!("home.orders")))
    .add(Card::new().title(t!("home.stock")))
    .add(Card::new().title(t!("home.people")))
```

## List

Строки одна под другой в `<ul>`. У каждого `ListItem` есть заголовок, а также может быть небольшое изображение в начале (те же безопасные адреса, что и у изображений карточек: путь, `https:` или `data:image/`), подзаголовок и короткий служебный текст в конце. С `.link(screen, params)` вся строка становится одной ссылкой, поэтому это одна остановка в порядке табуляции с видимой рамкой фокуса, и она открывается без перезагрузки страницы. Длинный текст переносится; на телефонах служебный текст перемещается под заголовок, а на страницах с письмом справа налево строка отражается зеркально.

`List::new()` содержит переданные ему элементы. `List::of(action)` загружает строки через действие (action) того же вида, что использует DataGrid, и разбивается на страницы как [сетка карточек](catalog.md#card-grid): 20 строк с кнопкой "Show more", если `paging` не задаёт иное, варианты сортировки, поиск на сервере через `.search(text)` и проверка доступа действия для каждой страницы.

```rust
List::new()
    .title(t!("team.title"))
    .item(ListItem::new("Ada Lovelace").subtitle(t!("team.math")))
    .item(ListItem::new("Alan Turing").subtitle(t!("team.computing")).meta(t!("team.lead")))

List::of(search_people)
    .title(t!("people.title"))
    .item(|p: &Person| {
        ListItem::new(p.name.clone())
            .image(p.photo.clone())
            .subtitle(p.city.clone())
            .meta(p.joined.format(&locale))
            .link(person, PersonParams { id: p.id })
    })
    .sort_option(t!("people.by_name"), Person::name, false)
    .paging(Paging::pages(20))
```

## Avatar

Круглое изображение человека или команды размером 32, 40 или 64 пикселя (`AvatarSize::Small`, `Medium`, `Large`). Имя обязательно: это альтернативный текст и источник инициалов, которые показываются, когда изображения нет или когда оно находится не на хосте, разрешённом `img-src` приложения (то же правило, что и у `Image`). Инициалы следуют правилам прописных букв языка, поэтому турецкая `i` становится `İ`. Когда имя написано прямо рядом с аватаром, `.decorative()` скрывает аватар от программ чтения с экрана, чтобы они не читали имя дважды.

```rust
Avatar::new(p.name.clone()).image(p.photo.clone()).size(AvatarSize::Large)
Avatar::new(p.name.clone()).size(AvatarSize::Small).decorative()
```

## Spoiler

Содержимое, скрытое, пока читатель его не откроет, например ответ на вопрос. Это встроенный раскрывающийся элемент (`<details>` и `<summary>`), поэтому он работает с клавиатурой и программами чтения с экрана без каких-либо скриптов, а содержимое не входит в порядок чтения, пока его не откроют. Подпись задаёт приложение.

```rust
Spoiler::new(t!("quiz.show_answer")).add(Paragraph::new(answer.clone()))
```

## AlphaIndex

Полоса букв, каждая из которых ссылается на экран с этой буквой в параметрах, например на людей, чьи имена начинаются с неё. Буквы берутся из языка пользователя в его собственном порядке (`zeyn::ui::alphabet`): в турецком `Ç Ğ I İ Ö Ş Ü` стоят на своих местах, в испанском есть `Ñ`, у русского и арабского свои алфавиты, а все остальные языки получают от `A` до `Z`. Буква показываемого экрана отмечается `aria-current="page"` (турецкая `i` отмечает `İ`), а `.other()` добавляет в конце ссылку `#` для имён, начинающихся с чего-то другого. Ссылки открываются без перезагрузки страницы и на телефонах переносятся на несколько строк.

```rust
#[screen(route = "/people/{letter}", public)]
pub fn people_by_letter(p: LetterParams) -> Screen {
    Screen::new(t!("people.title"))
        .body(AlphaIndex::new(people_by_letter, |l| LetterParams { letter: l.to_string() }).current(&p.letter).other())
}
```

## WeekSchedule

Семь столбцов дней со строками из действия, например занятия, смены или события недели. Действие того же вида, что использует DataGrid, и проверяется так же. `.day` сопоставляет строку с её днём: `Date`, `Option<Date>` (строки без даты пропускаются) или номер дня недели от 1 (понедельник) до 7 (воскресенье); что-либо другое не компилируется. Каждая строка показывается как `ListItem`, поэтому может ссылаться на экран. Неделя начинается с первого дня недели пользователя (понедельник в турецком, воскресенье в американском английском), сегодняшний день отмечен, дни без строк сообщают об этом, а на узких экранах дни располагаются друг под другом. Сервер загружает до `limit` строк (100, если не задано, не более 500) в порядке действия; передавайте действию строки нужной недели, например с фильтром по дате.

```rust
WeekSchedule::of(this_week_classes)
    .title(t!("classes.this_week"))
    .day(|c: &Class| c.date)
    .item(|c: &Class| {
        ListItem::new(c.name.clone())
            .meta(c.starts.to_string())
            .link(class, ClassParams { id: c.id })
    })
```
