# ソーシャル

ソーシャルページ向けのコンポーネントです。それぞれサーバーで描画され、そのコンポーネントを使うページでのみスタイルシートとスクリプトを読み込みます。

## StoryRing

`StoryRing` は、ある人のストーリーが閲覧者にとって新しいかどうかを示す、リング付きのアバターです。`StoryState::Unseen` はブランドカラーの太いリングを、`StoryState::Seen` は細い無彩色のリングを描きます。状態はサーバーから来るもので、アプリが閲覧者について保存した内容に基づきます。ブラウザーがこれを変更することはありません。`StoryRow` はリングをレールのように横へスクロールする一列に並べます。

```rust
StoryRow::new()
    .add(StoryRing::new(ada.name.clone(), StoryState::Unseen)
        .image(ada.photo.clone())
        .link(stories, StoryParams { person: ada.id }))
    .add(StoryRing::new(alan.name.clone(), StoryState::Seen).image(alan.photo.clone()))
```

`.link(screen, params)` を指定すると、リングはストーリーを表示する画面へのリンクになります。アクセシブルな名前は人の名前と状態で、たとえば「Ada Lovelace、未読のストーリー」です。リングの下に表示される名前も同じ書き出しなので、音声操作の利用者はそのまま発声できます。2 つの状態は色だけでなくリングの太さでも区別され、強制カラーモードでは既読のリングが破線で描かれます。画像は `Avatar` の規則に従います（アプリのパスまたは許可された `https` アドレス）。画像がない場合はイニシャルが表示されます。

リングは CSS だけで描かれます。スクリプトも画像も使いません。`stories.css`（2.2 KB）は、リングを含むページでのみ読み込まれます。1 列には最大 `MAX_STORY_RINGS`（100）個のリングを置けます。タッチ、トラックパッド、Shift+ホイールでスクロールでき、リングは所定の位置に吸着し、キーボードフォーカスを受けたリングは表示範囲へスクロールされます。列のどのリングにもリンクがない場合は列自体がフォーカスを受けるため、キーボードでもスクロールできます。

| キー | 動作 |
|---|---|
| Tab | 次のリングへ移動し、表示範囲へスクロールします |
| Enter | フォーカス中のリングのストーリーを開きます |
| Left, Right | 列自体にフォーカスがあるとき: 列をスクロールします |


## Lightbox

どの `Image` も `.lightbox()` で全画面に開けます。画面が許す限り大きく画像を表示し、キャプションとズームを備えたモーダルダイアログです。`.full(src)` は lightbox が表示する大きいファイルを指定し、ページは小さいほうを保持します。`.caption(text)` は下にキャプションを付けます(どちらも lightbox を有効にします)。`.video(source, file)` は画像をメディアソースの動画のポスターにし、lightbox がその動画を再生します。1 つの投稿の画像、または `Row`、`Stack`、`AutoGrid` のような 1 つのコンテナの画像は 1 組になり、矢印キーとスワイプでその間を移動します。

```rust
AutoGrid::new().min(140)
    .add(Image::new(p.thumb.clone()).alt(p.title.clone()).size(300, 300)
        .full(p.photo.clone())
        .caption(p.title.clone()))
    .add(Image::new(clip.poster.clone()).alt(clip.title.clone()).size(320, 180)
        .video("films", clip.file.clone()))
```

スクリプトがない場合、画像は自身のファイルへのリンクなので、それでも開きます。スクリプトがある場合、`lightbox.js`(13 KB、gzip で 4.4 KB)と `lightbox.css`(4 KB)は lightbox 画像を含むページでのみ読み込まれ、ダイアログは最初に開かれたときに作られます。ダイアログには開いている項目だけがあり、隣の項目の大きいファイルは画像として先読みされ、動画は先読みされません。サムネイルはぼかした状態ですぐに表示され、大きいファイルの読み込みが終わるとそれを覆います。デスクトップでの表示にかかる時間は約 16 ms です。

大きいファイルは画像のアドレス規則(アプリのパスまたは許可された `https` アドレス)に従い、規則に反する場合は画像自身のファイルが使われます。動画ファイルはソースの有効なメディア id でなければならず、ソースはリクエストごとに権限を確認し、範囲(range)配信を行います。ダイアログは W3C APG のダイアログパターンに従います。フォーカスは閉じるボタンに移り、Tab と Shift+Tab はダイアログ内にとどまり、閉じるとフォーカスはそれを開いた画像に戻ります(その間にフィードが画像をアンロードしていた場合は、その投稿に戻ります)。各画像リンクの名前は alt テキストで、alt が空の場合は「画像を開く」です。位置(「4 件中 2 件目」)は読み上げられます。動きは `prefers-reduced-motion` に従い、ダイアログが開いている間、背後のページはスクロールしません。

| Key | What it does |
|---|---|
| Enter | 画像上: lightbox を開きます |
| Right, Left | 次の項目と前の項目(右から左の言語では逆); 拡大した画像を移動します |
| Up, Down | 拡大した画像を移動します |
| Home, End | 最初と最後の項目 |
| +, -, 0 | 拡大、縮小、ズームのリセット |
| Escape | lightbox を閉じてフォーカスを戻します |
| Tab, Shift+Tab | ダイアログから出ずにボタン間を移動します |

ダブルクリック、ダブルタップ、ズームボタンでもズームでき、拡大した画像はドラッグで移動します。
