# Getting help

- Documentation: https://docs.zeynsoft.com. The same pages run as a Zeyn app with `cargo run -p zeyn-example-docs`.
- Component catalog: https://components.zeynsoft.com. Live demo: https://framework.zeynsoft.com.
- Questions and ideas: GitHub Discussions, once enabled for the repository.
- Bugs: open an issue with a minimal reproduction, the Zeyn version and your operating system. Use the bug report form.
- Feature requests: open an issue with the feature request form.
- Security problems: do not open an issue. Follow [SECURITY.md](SECURITY.md).

For AI agents, the documentation index is at https://docs.zeynsoft.com/llms.txt. [AGENTS.md](AGENTS.md) covers work on Zeyn itself and `skills/zeyn/SKILL.md` covers building apps with Zeyn.
