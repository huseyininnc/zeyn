أخطاء مترجم مكتوبة للوكيل الذي يقرؤها

كل قاعدة يستطيع المترجم فرضها تأتي مع اختبار يثبت أن الشيفرة الخاطئة تفشل، ورسالة تقول ما يجب تغييره. هذا بناء حقيقي لإجراء نسي أن يحدد من يحق له تشغيله.

  1. يكتب الوكيل إجراءً

    يؤرشف منتجًا ويطلب من المستخدم التأكيد أولًا، لكنه لا يعلن أي صلاحية.

    /// Archives a product by its code.
#[action(audit, confirm)]
pub async fn archive_product(code: String) -> Result<()> {

  2. يتوقف البناء

    تسمّي الرسالة المشكلة وكلا الحلين: إضافة صلاحية، أو وسم الإجراء بـ public.

    error: action `archive_product` has no permission
         = help: add `permission = "..."`, or `public` if this action is meant to be open to everyone
 --> src/main.rs:5:14
  |
5 | pub async fn archive_product(code: String) -> Result<()> {
  |              ^^^^^^^^^^^^^^^

  3. يطبّق الوكيل سطر المساعدة

    الآن يتحقق الخادم من الصلاحية في كل استدعاء، سواء جاء من صفحة أو من API أو من وكيل.

    - #[action(audit, confirm)]
+ #[action(permission = "stock.product.write", audit, confirm)]
  pub async fn archive_product(code: String) -> Result<()> {

النوع نفسه من الرسائل يغطي المجموع على عمود نصي، ومفتاح ترجمة مفقودًا من ملف لغة، وإجراءً لا يعيد Result. لكل واحدة منها اختبار compile_fail وملاحظة #[diagnostic::on_unimplemented].

يعمل الوكلاء بصلاحيات المستخدم المسجّل

وكلاء يستخدمون تطبيقك

يتصرف الوكيل بصفة المستخدم الذي يعمل لحسابه. ولا يرى أبدًا أدوات لشاشات أو إجراءات لا يحق لذلك المستخدم فتحها.

permission = "stock.product.write"
يُفحص في كل استدعاء، من صفحة أو API أو وكيل.
confirm
لا يجوز للنموذج تشغيل الإجراء إلا بعد أن يؤكده المستخدم في التطبيق.
ai = false
لا يُعرض الإجراء على أي نموذج أبدًا.
audit
يُسجَّل كل استدعاء، وتُوسم استدعاءات الوكلاء.
Agents::read_only()
يستطيع الوكلاء البحث لكن لا يستطيعون الحفظ. اختر read_write() فقط عندما ينبغي أن يغيّروا البيانات.

وكلاء يكتبون تطبيقك

يعدّ zeyn new الأمر zeyn mcp، وهو خادم MCP لوكلاء البرمجة، بجانب ملف AGENTS.md بقواعد المشروع.

zeyn_docs
مرجع الإطار حسب الموضوع: القواعد واللغة والبروتوكول والمعمارية
zeyn_describe
الميزات والشاشات والمسارات والوصول وواجهات API والترجمات المفقودة
zeyn_check
يترجم ويبلغ عن المشكلات
zeyn_test
يشغّل الاختبارات ويعيد نهاية المخرجات
zeyn_new_feature
ينشئ مجلد ميزة ويسجّلها

DataGrid يبقى سريعًا عند مليون صف

يضم أرشيف الطلبات في العرض التجريبي مليون طلب. يتنقل الجدول بينها بالتمرير الافتراضي بينما يرتّب الخادم ويصفّي ويقسّم إلى صفحات. وتشرح وثائق DataGrid كيف يتم ذلك.

  • مرشحات مكتوبة النوع لكل عمود
  • مجاميع على كل الصفوف المطابقة
  • التجميع والأشجار والتفاصيل الرئيسية
  • تحرير مباشر مع فحص إصدار الصف
  • أعمدة مثبّتة وإجراءات جماعية وتصدير CSV وExcel

لا تكتب HTML ولا CSS ولا JavaScript. الشاشات بلغة Rust، ويعرضها الخادم، وبيئة تشغيل صغيرة في المتصفح تطبّق التغييرات.

ما الموجود في الصندوق

Zeyn في مرحلة ألفا بكامله. الأجزاء الموسومة بمستقرة هي النواة والأقل عرضة للتغيير. الأجزاء التجريبية تعمل ومختبرة، لكن توقّع تغييرات أكبر بين الإصدارات.

DataGrid مستقر
تمرير افتراضي على مليون صف، ومرشحات مكتوبة النوع، ومجاميع، وتجميع، وتحرير مباشر، وتصدير CSV وExcel
النماذج مستقر
كل أنواع الحقول، وتحقق مشترك بين الخادم والمتصفح وAPI، وفحص تعارض إصدار الصف
الإجراءات مستقر
مدخلات مكتوبة النوع، وواجهة JSON API مع OpenAPI، وأدوات لوكلاء الذكاء الاصطناعي تعمل بصلاحيات المستخدم
نواة الأمان مستقر
صلاحيات على كل إجراء، وCSRF، وCSP صارمة، والتدقيق وتدقيق القراءة، وإخفاء الحقول، وحدود المعدل
قواعد البيانات تجريبي
PostgreSQL وOracle 11g أو أحدث، مع مؤشرات keyset والمعاملات والتدفقات وعمليات الترحيل
تسجيل الدخول والحسابات تجريبي
OpenID Connect وJWT وMFA ومفاتيح المرور، ونظام حسابات اختياري بشاشات جاهزة
سطح المكتب تجريبي
ملف تنفيذي واحد في WebView النظام يعمل دون اتصال
جزر WASM تجريبي
Rust مترجمة إلى WebAssembly للمكونات الثقيلة، مع استدعاءات إجراءات مكتوبة النوع
الوقت الفعلي تجريبي
غرف WebSocket مع مستندات CRDT للتحرير الحي، بذاكرة محدودة
مساعد الذكاء الاصطناعي تجريبي
مساعد مضمّن لأي نموذج لغوي كبير يسأل المستخدم قبل أن يكتب

حجم صورة الحاوية لتطبيق مولَّد نحو 43 ميغابايت، ويستخدم التطبيق الخامل بضعة ميغابايت من الذاكرة. راجع Docker في وثائق CLI.

أين يقف Zeyn

Zeyn برنامج في مرحلة ألفا. ما تصفه الوثائق يُترجم ومختبر، لكن واجهات البرمجة ما زالت تتغير. يُظهر العرض التجريبي الحي أين يقف اليوم.

cargo install zeyn-cli
zeyn new my-app
cd my-app
cargo run

تعمل مع وكيل برمجة؟ أعطه docs.zeynsoft.com/llms.txt. فهو يطلب من الوكيل تثبيت CLI وإنشاء المشروع واتباع قواعده.
