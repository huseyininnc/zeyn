AIエージェントが書く業務アプリのためのRustフレームワーク

コードは人がレビューします。安全性はコンパイラとフレームワークが守ります。Zeynはオープンソースで、axumを基盤に、グリッド、フォーム、ワークフローが中心のアプリ向けに作られています。

読み手のエージェントのために書かれたコンパイラエラー

コンパイラが強制できるすべてのルールには、誤ったコードが失敗することを証明するテストと、何を直すべきかを示すメッセージが付いています。これは、誰が実行できるかを宣言し忘れたアクションの実際のビルドです。

  1. エージェントがアクションを書く

    商品をアーカイブし、先にユーザーへ確認を求めますが、権限を宣言していません。

    /// Archives a product by its code.
#[action(audit, confirm)]
pub async fn archive_product(code: String) -> Result<()> {

  2. ビルドが止まる

    メッセージは問題と、2つの修正方法を示します。権限を追加するか、アクションを public にします。

    error: action `archive_product` has no permission
         = help: add `permission = "..."`, or `public` if this action is meant to be open to everyone
 --> src/main.rs:5:14
  |
5 | pub async fn archive_product(code: String) -> Result<()> {
  |              ^^^^^^^^^^^^^^^

  3. エージェントがヘルプ行に従う

    これでサーバーは、ページ、API、エージェントのどこからの呼び出しでも、毎回権限を確認します。

    - #[action(audit, confirm)]
+ #[action(permission = "stock.product.write", audit, confirm)]
  pub async fn archive_product(code: String) -> Result<()> {

同じ種類のメッセージが、テキスト列への合計、ロケールファイルにない翻訳キー、Result を返さないアクションにも用意されています。それぞれに compile_fail テストと #[diagnostic::on_unimplemented] の注記があります。

エージェントはサインイン中のユーザーの権限で動作します

アプリを使うエージェント

エージェントは、その依頼元のユーザーとして動作します。そのユーザーが開けない画面やアクションのツールは、エージェントには見えません。

permission = "stock.product.write"
ページ、API、エージェントのどこからの呼び出しでも、毎回確認されます。
confirm
ユーザーがアプリで確認した後にのみ、モデルはアクションを実行できます。
ai = false
このアクションはモデルに提供されません。
audit
すべての呼び出しが記録され、エージェントによる呼び出しには印が付きます。
Mcp::read_only()
エージェントは検索できますが、保存はできません。データを変更させる場合にのみ read_write() を選びます。

アプリを書くエージェント

zeyn new は、コーディングエージェント向けのMCPサーバーである zeyn mcp を設定し、プロジェクトのルールを記した AGENTS.md を並べて配置します。

zeyn_docs
トピック別のフレームワークリファレンス: ルール、言語、プロトコル
zeyn_describe
Feature、画面、ルート、アクセス、API、不足している翻訳
zeyn_check
コンパイルして問題を報告
zeyn_test
テストを実行し、出力の末尾を返す
zeyn_new_feature
Featureのフォルダーを作成して登録

100万行でも高速なDataGrid

デモの注文アーカイブには100万件の注文があります。グリッドは仮想スクロールで注文を表示し、並べ替え、絞り込み、ページ送りはサーバーが行います。仕組みは DataGridのドキュメント で説明しています。

  • すべての列に型付きフィルター
  • 一致するすべての行の合計
  • グループ化、ツリー、マスター詳細
  • 行バージョンチェック付きのインライン編集
  • 列の固定、一括操作、CSVとExcelへのエクスポート

HTML、CSS、JavaScriptを書く必要はありません。画面はRustで書き、サーバーが描画し、ブラウザー内の小さなランタイムが変更を適用します。

含まれているもの

Zeyn全体がアルファ版です。安定と記した部分は中核で、変更される可能性が最も低い部分です。実験的な部分は動作しテストされていますが、バージョン間で大きく変わることがあります。

DataGrid 安定
100万行 に対応した仮想スクロール、型付きフィルター、合計、グループ化、インライン編集、CSVとExcelへのエクスポート
フォーム 安定
すべての項目タイプ、サーバー、ブラウザー、APIで共通のバリデーション、行バージョンの競合チェック
アクション 安定
型付きの入力、OpenAPI付きのJSON API、ユーザーの権限で動作するAIエージェント用ツール
セキュリティの中核 安定
すべてのアクションの権限、CSRF、厳格なCSP、監査と閲覧監査、項目のマスキング、レート制限
データベース 実験的
PostgreSQLと、Oracle 11g以降。キーセットカーソル、トランザクション、ストリーム、マイグレーションに対応
サインインとアカウント 実験的
OpenID Connect、JWT、MFA、パスキー、すぐに使える画面を備えた任意のアカウントシステム
デスクトップ 実験的
システムのWebViewで動作する、オフライン対応の単一の実行ファイル
WASMアイランド 実験的
重いコンポーネント向けにWebAssemblyへコンパイルしたRust。型付きのアクション呼び出しに対応
リアルタイム 実験的
ライブ編集のためのCRDTドキュメントを備えたWebSocketルーム。メモリは上限付き
AIアシスタント 実験的
書き込む前にユーザーへ確認する、任意のLLM向けの組み込みアシスタント

生成されたアプリのコンテナイメージは約43 MBで、アイドル状態のアプリが使うメモリは数MBです。詳しくは CLIドキュメントのDocker を参照してください。

Zeynの現状

Zeynはアルファ版のソフトウェアです。ドキュメントに書かれていることはコンパイルでき、テストされていますが、APIは今後も変更されます。現状はライブデモで確認できます。

cargo install zeyn-cli
zeyn new my-app
cd my-app
cargo run

コーディングエージェントを使っていますか？ docs.zeynsoft.com/llms.txt を渡してください。CLIのインストール、プロジェクトの作成、プロジェクトのルールに従うことをエージェントに伝えます。
