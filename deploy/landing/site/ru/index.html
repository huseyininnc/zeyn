Альфа. API ещё меняются.

Фреймворк на Rust для бизнес-приложений, которые пишут ИИ-агенты

Код проверяют люди. Безопасность обеспечивают компилятор и фреймворк. Zeyn с открытым исходным кодом построен на axum и предназначен для приложений, полных таблиц, форм и рабочих процессов.

Ошибки компилятора, написанные для агента, который их читает

Каждое правило, которое может проверить компилятор, сопровождается тестом, доказывающим, что неверный код не собирается, и сообщением о том, что нужно изменить. Это настоящая сборка действия, в котором забыли указать, кому его можно выполнять.

  1. Агент пишет действие

    Оно архивирует товар и сначала просит пользователя подтвердить, но не объявляет права.

    /// Archives a product by its code.
#[action(audit, confirm)]
pub async fn archive_product(code: String) -> Result<()> {

  2. Сборка останавливается

    Сообщение называет проблему и оба способа её исправить: добавить право или пометить действие как public.

    error: action `archive_product` has no permission
         = help: add `permission = "..."`, or `public` if this action is meant to be open to everyone
 --> src/main.rs:5:14
  |
5 | pub async fn archive_product(code: String) -> Result<()> {
  |              ^^^^^^^^^^^^^^^

  3. Агент применяет подсказку

    Теперь сервер проверяет право при каждом вызове, придёт он со страницы, из API или от агента.

    - #[action(audit, confirm)]
+ #[action(permission = "stock.product.write", audit, confirm)]
  pub async fn archive_product(code: String) -> Result<()> {

Такие же сообщения есть для суммы по текстовому столбцу, для ключа перевода, отсутствующего в файле локали, и для действия, не возвращающего Result. У каждого есть тест compile_fail и примечание #[diagnostic::on_unimplemented].

Агенты работают с правами вошедшего пользователя

Агенты, которые используют ваше приложение

Агент действует от имени пользователя, для которого работает. Он никогда не видит инструментов для экранов и действий, недоступных этому пользователю.

permission = "stock.product.write"
Проверяется при каждом вызове: со страницы, из API или от агента.
confirm
Модель может выполнить действие только после того, как пользователь подтвердит его в приложении.
ai = false
Действие никогда не предлагается модели.
audit
Каждый вызов записывается, вызовы агентов помечаются.
Mcp::read_only()
Агенты могут искать, но не сохранять. Выбирайте read_write() только когда им нужно менять данные.

Агенты, которые пишут ваше приложение

zeyn new настраивает zeyn mcp, MCP-сервер для агентов-программистов, рядом с файлом AGENTS.md с правилами проекта.

zeyn_docs
Справочник по фреймворку по темам: правила, язык, протокол
zeyn_describe
Features, экраны, маршруты, доступ, API и недостающие переводы
zeyn_check
Компилирует и сообщает о проблемах
zeyn_test
Запускает тесты и возвращает конец вывода
zeyn_new_feature
Создаёт папку feature и регистрирует её

DataGrid, который остаётся быстрым на миллионе строк

В архиве заказов демо один миллион заказов. Таблица прокручивает их с виртуальной прокруткой, а сортировку, фильтрацию и разбиение на страницы выполняет сервер. Как это работает, объясняет документация DataGrid.

  • Типизированные фильтры для каждого столбца
  • Итоги по всем подходящим строкам
  • Группировка, деревья и «главная запись и детали»
  • Редактирование прямо в таблице с проверкой версии строки
  • Закреплённые столбцы, массовые действия, экспорт в CSV и Excel

Вы не пишете HTML, CSS и JavaScript. Экраны написаны на Rust, сервер их отображает, а небольшой исполняющий модуль в браузере применяет изменения.

Что входит в комплект

Zeyn в целом находится в альфа-версии. Части с пометкой «стабильно» составляют ядро и меняются реже всего. Экспериментальные части работают и протестированы, но между версиями возможны более крупные изменения.

DataGrid Стабильно
Виртуальная прокрутка миллиона строк, типизированные фильтры, итоги, группировка, редактирование в таблице, экспорт в CSV и Excel
Формы Стабильно
Все типы полей, проверка, общая для сервера, браузера и API, обнаружение конфликтов версий строк
Действия Стабильно
Типизированные входные данные, JSON API с OpenAPI и инструменты для ИИ-агентов, работающие с правами пользователя
Ядро безопасности Стабильно
Права на каждое действие, CSRF, строгий CSP, аудит и аудит чтения, маскирование полей, ограничение частоты запросов
Базы данных Экспериментально
PostgreSQL и Oracle 11g или новее: курсоры по ключу, транзакции, потоки и миграции
Вход и учётные записи Экспериментально
OpenID Connect, JWT, MFA, ключи доступа и необязательная система учётных записей с готовыми экранами
Настольное приложение Экспериментально
Один исполняемый файл в системном WebView, работающий без сети
WASM-острова Экспериментально
Rust, скомпилированный в WebAssembly, для тяжёлых компонентов, с типизированными вызовами действий
Реальное время Экспериментально
Комнаты WebSocket с документами CRDT для совместного редактирования, с ограниченным объёмом памяти
ИИ-ассистент Экспериментально
Встроенный ассистент для любой LLM, который спрашивает пользователя перед записью

Образ контейнера сгенерированного приложения занимает около 43 МБ, а простаивающее приложение использует несколько МБ памяти. См. Docker в документации CLI.

Текущее состояние Zeyn

Zeyn находится в альфа-версии. То, что описано в документации, компилируется и протестировано, но API ещё меняются. Живая демо показывает текущее состояние.

cargo install zeyn-cli
zeyn new my-app
cd my-app
cargo run

Работаете с агентом-программистом? Дайте ему docs.zeynsoft.com/llms.txt. Файл предписывает агенту установить CLI, создать проект и следовать правилам проекта.
