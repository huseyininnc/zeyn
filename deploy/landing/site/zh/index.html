为阅读它们的智能体而写的编译器错误

编译器能够强制的每条规则都配有一个证明错误代码会失败的测试，以及一条说明如何修改的消息。下面是一次真实构建：某个 action 忘了声明谁可以运行它。

  1. 智能体编写一个 action

    它会归档商品，并先请用户确认，但没有声明权限。

    /// Archives a product by its code.
#[action(audit, confirm)]
pub async fn archive_product(code: String) -> Result<()> {

  2. 构建中止

    消息指出了问题和两种修复方式：添加权限，或将该 action 标记为 public。

    error: action `archive_product` has no permission
         = help: add `permission = "..."`, or `public` if this action is meant to be open to everyone
 --> src/main.rs:5:14
  |
5 | pub async fn archive_product(code: String) -> Result<()> {
  |              ^^^^^^^^^^^^^^^

  3. 智能体采用 help 行的建议

    现在服务器会在每次调用时检查权限，无论调用来自页面、API 还是智能体。

    - #[action(audit, confirm)]
+ #[action(permission = "stock.product.write", audit, confirm)]
  pub async fn archive_product(code: String) -> Result<()> {

同类消息还覆盖对文本列求和、语言文件缺少翻译键，以及不返回 Result 的 action。每一种都有一个 compile_fail 测试和一条 #[diagnostic::on_unimplemented] 说明。

智能体使用已登录用户的权限工作

使用你的应用的智能体

智能体以其所服务的用户身份行动。它看不到该用户无权打开的界面或 action 对应的工具。

permission = "stock.product.write"
每次调用都会检查，无论来自页面、API 还是智能体。
confirm
只有用户在应用中确认后，模型才能运行该 action。
ai = false
该 action 永远不会提供给模型。
audit
每次调用都会被记录，智能体的调用会被标记。
Agents::read_only()
智能体可以搜索但不能保存。仅在需要智能体修改数据时才选择 read_write()。

编写你的应用的智能体

zeyn new 会配置 zeyn mcp（面向编码智能体的 MCP 服务器），并附带包含项目规则的 AGENTS.md。

zeyn_docs
按主题查阅框架参考：规则、语言、协议、架构
zeyn_describe
Feature、界面、路由、访问权限、API 和缺失的翻译
zeyn_check
编译并报告问题
zeyn_test
运行测试并返回输出末尾
zeyn_new_feature
创建 feature 文件夹并注册

百万行数据下依然流畅的 DataGrid

演示中的订单归档包含一百万条订单。表格通过虚拟滚动浏览这些数据，排序、筛选和分页由服务器完成。具体做法见 DataGrid 文档。

  • 每一列都有类型化筛选器
  • 对所有匹配行进行合计
  • 分组、树形和主从明细
  • 带行版本检查的行内编辑
  • 固定列、批量操作、CSV 和 Excel 导出

你不需要编写 HTML、CSS 或 JavaScript。界面用 Rust 编写，由服务器渲染，浏览器中的小型运行时负责应用变更。

功能一览

Zeyn 整体处于 alpha 阶段。标记为稳定的部分是核心，最不容易变化。实验性部分可用且经过测试，但版本之间可能有较大变更。

DataGrid 稳定
对百万行数据的虚拟滚动、类型化筛选器、合计、分组、行内编辑、CSV 和 Excel 导出
表单 稳定
所有字段类型，服务器、浏览器和 API 共用的校验，行版本冲突检查
Action 稳定
类型化输入，带 OpenAPI 的 JSON API，以及以用户权限运行的 AI 智能体工具
安全核心 稳定
每个 action 的权限、CSRF、严格的 CSP、审计和读取审计、字段脱敏、限流
数据库 实验性
PostgreSQL，以及 Oracle 11g 或更高版本，支持 keyset 游标、事务、流和迁移
登录与账户 实验性
OpenID Connect、JWT、MFA、通行密钥，以及带现成界面的可选账户系统
桌面 实验性
在系统 WebView 中运行的单个可执行文件，可离线工作
WASM islands 实验性
面向重型组件、编译为 WebAssembly 的 Rust，支持类型化的 action 调用
实时 实验性
用于实时编辑的 WebSocket 房间和 CRDT 文档，内存有上限
AI 助手 实验性
适用于任意 LLM 的内嵌助手，写入前会询问用户

生成的应用的容器镜像约 43 MB，空闲时只占用几 MB 内存。参见 CLI 文档中的 Docker。

Zeyn 的现状

Zeyn 是 alpha 软件。文档描述的内容都能编译并经过测试，但 API 仍在变化。在线演示展示了当前的进展。

cargo install zeyn-cli
zeyn new my-app
cd my-app
cargo run

正在使用编码智能体？把 docs.zeynsoft.com/llms.txt 交给它。其中会告诉智能体安装 CLI、创建项目并遵循项目规则。
